# Prestemos · frente

Interfaz en Angular de Prestemos. La documentación completa está en el README de la raíz del repositorio.

| Comando | Qué hace |
|---------|----------|
| `npm start` | Sirve la app en `http://localhost:4200` contra el backend en `http://localhost:8080` |
| `npm run start:mock` | Sirve la app con el simulador de la API (no necesita backend) |
| `npm test` | Pruebas unitarias (Vitest) |
| `npm run lint` | ESLint y reglas de marca |
| `npm run build` | Build de producción |
